# 07.7 — Image SEO & Image Element Optimization

Images are not decoration that automatically makes a page better. Every image should have a purpose, context, and appropriate textual representation. When an important image carries information that cannot be understood without seeing it, the page loses part of its meaning for users and systems that process content non-visually.

Domain 07.7 focuses on **selecting, placing, and describing images as page elements**. File formats, compression, responsive delivery, lazy loading, CDNs, and technical performance belong to Domain 10 — Technical SEO.

## 1. What Image SEO Covers

Image SEO makes images relevant, understandable, and connected to page context. Google explains that it obtains image information from multiple sources, including page content, nearby text, captions, image titles, filenames, alt text, and visual-understanding technologies. [1]

The goal is not merely to make an image appear in Google Images. Images should help users understand a page and, where relevant, provide enough context for search engines to interpret them.

Domain 07.7 has four focus areas:
- **Image relevance:** the image supports the page's purpose and content.
- **Image context:** the image is placed near text explaining its relevance.
- **Text alternatives:** alt text describes image information or function in context.
- **Image naming:** filenames are descriptive and consistent.

## 2. Image Purpose Comes First

Before writing alt text or changing a filename, determine the image's function. W3C WAI distinguishes images by their communication purpose. The appropriate text alternative depends on use context, not simply on the visible object. [2]

| Image type | Purpose | Alternative text approach |
|---|---|---|
| Informative | Communicates information or a concept | Describe the important information conveyed by the image. |
| Decorative | Adds visual styling without information | Use an empty alt value so assistive technology can skip it. |
| Functional | Is the only content of a link or button | Describe the control's function or destination, not merely the icon's appearance. |
| Complex | Communicates complex data or information, such as a chart or diagram | Provide concise alt text and a full explanation in nearby text or an equivalent alternative. |
| Text in image | Displays text unavailable elsewhere | Make important text available as a text alternative; prefer ordinary HTML text where possible. |

The same image may belong to different categories on different pages. A product photo may be informative on a product page but decorative when it merely repeats information fully explained by adjacent text. Decide based on its actual function. [2]

## 3. Writing Useful Alt Text

Alt text is the value of the alt attribute on an HTML img element. It provides a text alternative for image information or function. Google uses alt text alongside page content and computer vision to understand image subjects. Alt text may also serve as anchor text when an image is a link. [1]

### 3.1 Describe the information, not every pixel
Write what users need to understand the image's role in context.

Illustrative example: an article explains how bicycle disc brakes work.

Less useful:
- Image: alt="image"

More informative:
- Image: alt="Disc brake caliper gripping the rotor on a bicycle wheel"

The description need not narrate irrelevant visual details. W3C recommends that text alternatives convey the essential information communicated by an image. [2]

### 3.2 Keep it contextual
Alt text should follow the image's function on the page, not a universal template.

A bird photograph in a birdwatching article may need to identify the species if identification is central. In a garden-design article, it may be enough to describe the bird in the garden if species identity is irrelevant.

### 3.3 Avoid keyword stuffing
Google explicitly warns against filling alt text with keyword lists. Use relevant terms naturally only when they genuinely describe the image and page context. [1]

Do not write a string such as “running shoes jogging shoes sports shoes cheap shoes best shoes.” Instead describe the actual visual, such as “Black running shoe with a thick sole and reflective details.”

### 3.4 Decorative images need empty alt
For an image used only for decoration, use an empty alt value. Do not simply omit the alt attribute. W3C explains that an empty alt lets assistive technology skip decorative images; when the attribute is missing, some screen readers may announce the filename. [3]

### 3.5 Functional images describe the action
If an image is the only content of a button or link, its alternative text should describe the control's function or destination.

Example: a cart icon link may use alternative text such as “View shopping cart.” If adjacent link text already explains the same destination and the image is decorative, an empty alt value may avoid repetition. [2][4]

### 3.6 Complex images need more than one-line alt
Charts, process diagrams, maps, and infographics may contain more information than can be summarized in one alt sentence.

Use concise alt text to identify the image's purpose, then provide the full explanation as HTML text, a data table, or nearby description. Do not force the entire chart into one attribute. W3C identifies complex charts and diagrams as images requiring a complete text equivalent. [2][5]

## 4. Image Filename

Filenames can provide Google with a lightweight clue about an image's subject. Google recommends short, descriptive filenames rather than generic names such as IMG00023.JPG. A filename does not replace alt text or page context. [1]

Examples:

| Generic filename | More descriptive filename |
|---|---|
| IMG00023.jpg | bicycle-disc-brake-caliper.jpg |
| image1.png | checkout-process-diagram.png |
| DSC_9081.webp | analytics-dashboard-view.webp |

Practical principles:
- Describe the main subject concisely.
- Use a consistent naming pattern.
- Avoid keyword lists and repeated words.
- Do not rename a file when the benefit does not justify the risk of changing an image URL already in use.
- Ensure the file extension matches the actual format; formats and delivery belong to Domain 10. [1]

Google does not define a filename formula or keyword count as a ranking rule.

## 5. Image Placement and Surrounding Context

Place images near relevant text. Google says nearby text can help it understand an image's subject and meaning in page context. The page embedding an image can also influence how and where that image appears in Google Search. [1]

In practice:
- Place a diagram near the section explaining its process.
- Place product photos near the relevant product information.
- Avoid stock images with no clear relationship to the topic.
- Do not use a generic image where a visual should show a specific detail.
- Ensure captions, alt text, and nearby text do not contradict one another.

### 5.1 Captions
A caption is visible text that explains or contextualizes an image. It is useful when readers need identification, source, context, or visual interpretation.

Captions are not required for every image. Do not add them merely to insert keywords. If an image is clear and a caption adds no information, do not force one.

Captions and alt text need not be identical:
- Alt text provides an alternative for image information/function.
- A caption provides visible context for all readers.

Google identifies captions and image titles as page information that may help it understand an image's subject. [1]

## 6. Image Relevance and Page-Level Consistency

Images should support page purpose. An attractive but irrelevant visual adds noise.

Review consistency across four elements:

| Element | Review question |
|---|---|
| Image itself | Does the visual actually depict the object or concept discussed? |
| Alt text | Does the text alternative convey the right information/function? |
| Nearby text and caption | Does surrounding context explain the image's relationship to the page? |
| Page purpose | Does the image help users complete a task or understand the topic? |

For visually dependent pages—product catalogues, tutorials, recipes, or identification guides—image accuracy has substantial editorial importance. Do not use an incorrect visual merely because its filename and alt text look SEO-friendly.

## 7. HTML Image Element: Authoring-Level Checks

For content images, use an HTML img element with suitable attributes. Google says it can find images from the src attribute of an img element, including when the element is inside picture; Google does not index images displayed only as CSS background images. [1]

Basic authoring example: a figure may contain an img element and a figcaption when the image and caption form a relevant content unit. These elements are not mandatory for every image.

Scope notes:
- Element choice and text alternatives belong to Domain 07.
- File format, compression, responsive dimensions, srcset, sizes, lazy loading, CDN, and loading performance belong to Domain 10.
- Image sitemaps and crawler image discovery are Domain 10 crawl/index implementation, with underlying system behavior in Domain 02. Google provides image sitemaps to help discover images that may not otherwise be found. [6]

## 8. Common Image SEO Problems

| Problem | Why it matters | Better approach |
|---|---|---|
| Empty alt on an informative image | Visual information is unavailable as text | Write an alternative conveying essential information |
| Missing alt on a decorative image | Assistive technology may announce the filename | Use an empty alt value |
| Keyword stuffing | Harms user experience and may be spammy | Describe image function naturally |
| Generic filename | Provides little subject context | Use concise descriptive naming where practical |
| Irrelevant image | Obscures page context | Choose a visual that supports the content |
| Image far from related text | Contextual relationship is harder to understand | Place it near relevant discussion |
| Complex chart without text explanation | Important information is unavailable to some users | Provide a description or equivalent data |
| Caption repeats alt text without added value | Adds noise | Distinguish caption and alt functions |
| Content image only as CSS background | Google says CSS images are not indexed | Use img for content images intended for discovery |
| Image URL changed without a plan | Existing references may break | Coordinate technical migration with Domain 10 |

## 9. Practical Image Optimization Workflow

1. **Inventory images.** Record important images on the page and their functions.
2. **Classify image purpose.** Determine whether each is informative, decorative, functional, or complex.
3. **Check relevance.** Confirm the visual fits the content and page purpose.
4. **Write alternative text.** Describe relevant information or function; use empty alt for decoration.
5. **Review filenames.** Replace generic names when sensible and technically safe.
6. **Review context.** Check nearby text, captions, and placement.
7. **Inspect HTML output.** Ensure content images use appropriate elements and attributes.
8. **Hand off technical delivery.** Validate formats, responsive delivery, loading, and performance with Domain 10.
9. **Recheck after publishing.** Ensure images and text alternatives render and function on the live page.

## 10. Quality-Control Checklist

- [ ] Every image has a clear purpose.
- [ ] Images are relevant to content and page purpose.
- [ ] Informative images have alt text conveying essential information.
- [ ] Decorative images use an empty alt value.
- [ ] Functional images describe the link or button purpose.
- [ ] Complex charts and diagrams have adequate text explanations.
- [ ] Alt text is concise, contextual, and free of keyword stuffing.
- [ ] Filenames are descriptive where practical and do not trigger unnecessary URL changes.
- [ ] Images appear near relevant text.
- [ ] Captions add context rather than merely repeat.
- [ ] Content images are not implemented only as CSS backgrounds.
- [ ] Quality, format, responsiveness, and technical performance are checked with Domain 10.

This checklist assesses authoring and implementation quality. It is not a ranking score or a guarantee of Google Images visibility.

## 11. Common Misconceptions

### 11.1 “Every image needs keyword-rich alt text”
Incorrect. Alt text follows image function. Decorative images use empty alt; inserting keywords into every image harms user experience. [1][2]

### 11.2 “Alt text is just an SEO field”
Incorrect. Alt text primarily provides a textual alternative for image information or function. Google also uses it as one source for understanding images. Both functions matter. [1][2]

### 11.3 “Filename alone is enough”
No. Google describes filenames as a lightweight clue. Alt text, page text, captions, and visual context also contribute. [1]

### 11.4 “Every image needs a caption”
No. A caption is useful when it adds visible context. It is not a universal requirement.

### 11.5 “CSS background images are equivalent to content images for Google Images”
Not according to current Google documentation: Google says CSS images are not indexed. Use an img element for content images intended for discovery. [1]

### 11.6 “Image optimization guarantees image-search rankings”
There is no guarantee. These practices help images be discovered and understood but do not guarantee indexing, thumbnail selection, or result position.

## Key Takeaways

- Image optimization starts with image function, not keywords.
- Alt text should describe image information or function in context.
- Decorative images use empty alt; complex images need fuller text alternatives.
- Descriptive filenames provide lightweight context, not a replacement for alt text.
- Placement near relevant text connects images to page context.
- Use img for content images intended for Google discovery; Google says CSS images are not indexed.
- Authoring optimization does not replace technical delivery and performance work.

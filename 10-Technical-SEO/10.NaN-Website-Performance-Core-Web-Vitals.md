# 10.10 — Website Performance & Core Web Vitals

Website performance work measures and improves how quickly and reliably a page responds and renders for users. Core Web Vitals are field-oriented user-experience metrics; they are not a complete performance model and should not be treated as a deterministic ranking formula.

## 1. Core concepts and mechanisms

The Core Web Vitals set includes Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS). Use current metric documentation for definitions, thresholds, and changes. Web.dev describes Core Web Vitals as field metrics with target thresholds intended to characterize real-world user experience. [1]

Field data records user experiences in real environments and varies by device, network, geography, and usage. Lab data is collected under controlled conditions and is useful for debugging and regression testing, but cannot reproduce the full distribution of real-user conditions. A single Lighthouse run is not a substitute for field data; field data may identify a problem without revealing its code-level cause.

Investigate server response and caching, critical rendering paths, JavaScript execution, image dimensions and formats, font loading, third-party scripts, layout reservations, and long-running main-thread tasks. Select fixes based on measured bottlenecks rather than generic checklists.

Record page/template, metric, data source, device context, time window, percentile, and release version. Google's page-experience guidance should be described precisely: do not claim that a score guarantees ranking improvements or that every optimization has a measurable search effect. Domain 14 owns organic outcome measurement; this topic owns technical performance diagnosis and remediation.

## 2. Practical validation

Use representative URLs and templates, inspect the actual HTTP response and rendered output, document the environment and date, and retest after production deployment. A tool result is evidence about the test it performed, not a universal certification.

## 3. Limitations and ownership

Attribute search-engine-specific behavior to the engine that documents it. Distinguish technical validity from indexing selection, ranking, and search presentation. Use adjacent-domain links from the [Domain 10 index](README.md) to preserve canonical ownership.
